# Module provenance

`3rr` brings three related server-management components into one repository:

- `control-plane` originated in `cs2-modded-server-panel`.
- `host-updater` originated in `cs2-auto-update`.
- `server-bootstrap` is a rewrite of bootstrap concepts from
  `cs2-modded-server-egg`; it is not a restored Pterodactyl runtime.

upstream license and notice files where applicable.
