# Module Provenance

`3rr` consolidates three related operator surfaces into one repository:

- `apps/operate/panel` originated in `cs2-modded-server-panel`.
- `apps/maintain/updater` originated in `cs2-auto-update`.
- `apps/provision/bootstrap` is a curated rewrite of bootstrap concepts from
  `cs2-modded-server-egg`; it is not a restored Pterodactyl runtime.

upstream license and notice files where applicable.
